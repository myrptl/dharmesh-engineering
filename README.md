# Dharmesh Engineering website (React + Vite)

    npm install
    npm run dev      # local development
    npm run build    # production files in dist/ (upload dist/ to your host)

Stack: React 18, Vite, Framer Motion. Fonts are self-hosted (no external requests).
Content lives in src/data.js and src/components/. Enquiry form posts to the same Google Apps Script URL as the old site (src/data.js -> SCRIPT_URL).
